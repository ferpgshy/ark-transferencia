# ARK Transferência

Pacote pra levar os mundos do ARK Survival Ascended pra outro PC.

## Como usar

1. Clica em **Code > Download ZIP** e extrai a pasta inteira.
2. No PC que vai receber: abre o ARK uma vez até o menu, fecha e roda o **`INSTALAR.bat`**.
3. Instala os mods que faltarem pelo menu de Mods do jogo, usando o `MODS_NECESSARIOS.txt`.

Pra atualizar o pacote com os mundos mais recentes, roda o **`ATUALIZAR_PACOTE.bat`** no PC de origem.

Detalhes completos no `LEIA-ME.txt`.

## O que tem aqui

| Pasta / arquivo | Conteúdo |
|---|---|
| `dados/Saved/SavedArksLocal` | Mundos: Ragnarok, Scorched Earth, The Center, Lost Colony e backup do The Island |
| `dados/Saved/Config/Windows` | Game.ini, GameUserSettings.ini, Engine.ini, Input.ini, PrimalConsole.ini |
| `INSTALAR.bat` | Acha o jogo (Steam em qualquer HD, Epic ou caminho manual), faz backup e instala |
| `ATUALIZAR_PACOTE.bat` | Recopia tudo do PC de origem, com opção de incluir os mods |
| `MODS_NECESSARIOS.txt` | Lista dos 57 mods ativos |

Os mods (cerca de 15 GB) não ficam no GitHub por causa do tamanho.
